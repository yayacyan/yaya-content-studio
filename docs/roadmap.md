# Roadmap

## v1: Local CLI

- Add content ideas
- Save Markdown drafts
- List recent ideas and drafts
- Record performance stats
- Analyze simple performance signals
- Suggest next topics with rule-based logic

## v2: Better Local Workflow

- Search and filter ideas
- Update status from idea to draft, published, or archived
- Export article bundles
- Add richer templates for paid articles
- Add weekly review reports

## v3: Optional Integrations

- Optional API-based summarization or rewriting
- Optional import from platform exports
- Optional calendar planning

Auto-publishing is intentionally out of scope until the local workflow is stable and trustworthy.
