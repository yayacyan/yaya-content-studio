# Workflow

## 1. Capture Ideas

Use:

```bash
python main.py new
```

Save raw topics from daily work, reading, conversations, Threads posts, and article comments.

## 2. Draft Locally

Use:

```bash
python main.py save
```

Draft in Markdown first. Keep note and Medium drafts separate when the audience or angle is different.

## 3. Publish Manually

Version 1 does not auto-publish. Copy the final draft to note, Medium, Threads, or X manually.

## 4. Record Results

Use:

```bash
python main.py stats
```

Record views, likes, comments, claps, sales, and memo after publishing.

## 5. Review Weekly

Use:

```bash
python main.py analyze
python main.py suggest
```

Use the output to decide which topics should become free resonance posts, series posts, or concrete paid articles.
